# Sprint Handoff Archive (`docs/handoffs/`)

This directory is **100% AI-managed**. Developers do not need to write or edit files here manually.

Whenever a sprint is completed (via `/close-sprint` or at the end of a sprint), the AI automatically generates `SPRINT_<N>_HANDOFF.md` here with:
- Created and modified files
- Registered routes and RBAC role guards
- Migrations and seeders verified
- Exact test/command results
- Context notes for the next fresh AI session

Every new AI session reads the latest handoff file in this folder alongside `docs/PROJECT_RULES.md`, `docs/SCHEMA.md`, `docs/SPRINT_STATUS.md`, and `docs/REQUIREMENTS.md`.
