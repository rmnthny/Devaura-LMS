# Sprint Handoffs

Each completed sprint receives a handoff that records the implementation, configuration, migrations, verification evidence, deferred work, and known limitations.

- [Sprint 3 working handoff](SPRINT_3_HANDOFF.md)
- [Sprint 4 circulation, notifications, and QA](SPRINT_4_HANDOFF.md)
- [Sprint 5 implementation, frontend contract, and QA](SPRINT_5_HANDOFF.md)

The [active handoff](../ACTIVE_HANDOFF.md) identifies the current checkout and release boundary. The Sprint 5 handoff records the workflows that remain deferred.

Create the next file as `SPRINT_<N>_HANDOFF.md` before merging that sprint.
